# FullFrame user guide · Guía de uso de FullFrame

FullFrame turns a set of photographs into an online exhibition. This guide is
for the people who use it: visitors, curators, jurors, invited authors and the
TYDAL administrators who set an exhibition up.

FullFrame convierte un conjunto de fotografías en una exposición en línea. Esta
guía es para quienes la usan: visitantes, comisarios, jurado, autores invitados
y los administradores de TYDAL que preparan una exposición.
