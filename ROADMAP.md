# FullFrame roadmap

FullFrame demonstrates TYDAL vaults through photography exhibitions. The current experience is documented in [README.md](README.md) and [the exhibition guide](docs/GUIDE.md).

Implemented: shared vault URL connection, machine-hash resource identity, Mosaic/Gallery/Wall views, theme and palette previews, optional jury, manual selection, publication and closing through vault write methods, and jury/scoring exports.

Next priorities:

- Test complete curator and visitor workflows with early adopters.
- Improve performance using measurements from real exhibitions.
- Improve accessibility and mobile behavior based on those tests.

Historical design proposals are preserved in Git history. They are not the current implementation contract.
